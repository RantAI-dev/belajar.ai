# belajar.ai

A learning app for school students: ask questions, follow guided lessons and practise, with every
answer taken from the student's own textbooks and linked to the page it came from.

- `rust/` — the server (Rust, axum): the `/v1` API and the built web app.
- `web/` — the web app (React, Vite, Tailwind).

Working on it: read `AGENTS.md`. The gate is `scripts/check.sh`.

This repository follows the [RantAI engineering guidelines](https://github.com/RantAI-dev/guidelines).
